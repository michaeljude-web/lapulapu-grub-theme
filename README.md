# Installation

# 1. Clone the repository

```bash
git clone https://github.com/michaeljude-web/lapulapu-grub-theme.git
cd lapulapu-grub-theme
```

### 2. Make the installer executable

```bash
chmod +x install.sh
```

### 3. Run the installer

```bash
sudo ./install.sh
```

### 4. Reboot

```bash
sudo reboot
```

---

# Uninstall

### 1. Make the uninstall script executable

```bash
chmod +x uninstall.sh
```

### 2. Run the uninstall script

```bash
sudo ./uninstall.sh
```
 ‎ 
---

| File | Description |
|------|-------------|
| `install.sh` | Installs the theme |
| `uninstall.sh` | Removes the theme |
| `theme.txt` | Main GRUB theme config |
